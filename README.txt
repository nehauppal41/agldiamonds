AUREVA — COMING SOON LANDING PAGE
=================================

Files:
- index.html
- assets/css/style.css
- assets/js/app.js
- assets/logo/aureva-logo.svg

Upload the entire folder contents to the website document root.
Open index.html directly; no PHP, framework or database is required.

NOTES

- CSS-only decorative animation plus a tiny IntersectionObserver script.
- Responsive for desktop, tablet and mobile.
- Reduced-motion preference is respected.
- The wording intentionally does not claim a specific accreditation or certification.
